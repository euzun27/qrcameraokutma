Sıra kontrolü: koddaki son sayı bir önceki doğru koddan "adım" kadar büyük olmalı (ör. PSK-000123 → PSK-000124), ön ve son ek aynı kalmalı. Farklı gelen kod YANLIŞ olur, sıra son doğru koddan devam eder. Bir poşet gerçekten eksikse "Sırayı son koddan devam ettir" ile yeni koddan devam edilir.
IP kamera için uygulamayı python sunucu.py ile açın; adres ?kamera=IP ile de verilebilir.
API yanıtı: HTTP 200 ve JSON içinde valid/gecerli/ok alanı true ise DOĞRU sayılır; alan yoksa 200 = DOĞRU, diğer durumlar YANLIŞ. Kayıt adresine her okuma {code, valid, time} JSON olarak POST edilir.
